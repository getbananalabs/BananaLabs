§ Documentation

Move a site off Framer: exact copy, source, machine-verified.

The full reference lives in the README on GitHub. This page is the short version.

01 What it does

BananaMigrator. is a command line tool and a Claude Code plugin. It moves a website off Framer onto your own hosting: it pulls an exact copy of the published site, extracts the project source through the Framer Server API, and verifies by machine that the copy is 1:1 with the original. No eyeballing: a machine makes the call.

02 Install

Add the Banana Labs marketplace, then install the plugin.

$ claude plugin marketplace add getbananalabs/BananaLabs
$ claude plugin install bananamigrator@bananalabs

03 How a site travels

01 Copy

Pulls an exact copy of the published site.

02 Source

Extracts the project source through the Framer Server API.

03 Verify

13 checks at 3 screen widths, plus real form flows.

04 Report

Snapshots and change reports, so every run is on record.

04 Commands

Inside Claude Code, ask for a migration in plain words and the plugin runs the steps for you. On the command line, every command takes the site name from sites/<site>.json.

pnpm mirror <site>exact copy of the published site; --refresh downloads everything again, --no-discover skips the runtime pass
pnpm serve <site>local preview of the copy; forms get 200 without sending anything
pnpm verify <site>13 checks and flows; --copy, --original, --pages, --viewports, --resolve host=ip, --flows [names], --flows-only
pnpm dump <site>the project source through the Server API, page texts completed from the mirror
pnpm export <site> --to <dir>hand the copy to the target site's repository
pnpm pull <site>mirror and dump in one go; --snapshot [--push] adds a snapshot
pnpm snapshot <site>the site as of now; --push uploads it to your S3 or R2 storage
pnpm snapshots <site>list the snapshots
pnpm diff <site> [a] [b]what changed: pages, files, texts, CMS, code, styles, redirects
bananamigrator --versionthe tool version, for support requests

Output lands in out/<site>/: mirror/, dump/, verify/report.json, snapshots/.
